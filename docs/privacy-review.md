# Privacy Review

Date: 2026-05-23

Scope:

- root repository files
- C# solution under `src/` and `tests/`
- public metadata intended for the first push to `MayukXT/AutoBingSearch`

Checks performed:

- repository was cloned fresh from GitHub before adding local project files
- excluded browser profiles, virtual environments, runtime screenshots, logs, caches, and generated files
- searched for common secret patterns: GitHub tokens, private keys, AWS keys, password assignments, token assignments, API key strings, and the local Windows user path
- searched for browser-account artifacts: cookies, `Login Data`, `Local State`, `edge_profile`, `.venv`, `.runtime`, and generated bytecode
- repeated the pattern scan after adding the C# tray app, tests, and documentation

Result:

- no secret values found
- no browser profile files copied
- no `config.json` copied
- no virtual environment or runtime state copied
- C# build output and publish artifacts are ignored
- remaining mentions of cookies/profile paths are documentation or code references explaining what must not be committed

Public config:

- machine-specific `config.json` remains ignored

Notes:

- `gitleaks` was not installed in this environment, so the scan used local repository inspection and targeted pattern searches.
- The C# app stores runtime configuration under `%APPDATA%\AutoBingSearch` and logs under `%LOCALAPPDATA%\AutoBingSearch\Logs`, never beside source code.
- The C# app copies browser profile data only into `%LOCALAPPDATA%\AutoBingSearch\BrowserProfiles` for local unattended runs; that directory is not part of the repository and must stay untracked.
